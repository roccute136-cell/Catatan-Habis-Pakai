Guide

Panduan alur stok dan import dari spreadsheet.

Alur Stok

  1. Catat barang yang perlu dibeli di Dashboard (lewat Input atau Import).
  2. Setelah barang dibeli, klik Sudah dibeli. Barang pindah ke halaman Stok dan hilang dari daftar permintaan.
  3. Di halaman Stok, klik Pakai setiap barang dipakai agar stok berkurang. Status menjadi Habis saat stok 0.
  4. Klik Beli lagi untuk memasukkan barang itu kembali ke daftar permintaan di Dashboard.

Jika barang dengan nama yang sama sudah ada di Stok, jumlahnya ditambahkan ke baris yang sama.

Langkah Import

  1. Unduh template di bawah, lalu isi dengan data barang Anda.
  2. Hapus baris contoh yang tidak diperlukan.
  3. Simpan file sebagai .xlsx, .xls, atau .csv.
  4. Buka Dashboard, klik Import, dan pilih file tersebut.
  5. Periksa jumlah barang pada konfirmasi, lalu klik OK.

Format kolom

NoNamaQtyHarga/Qty
1Lem G18000
2Cotton Bud2Rp7,000
3Gula0.510000
  • Judul kolom wajib ada di baris pertama: Nama, Qty (atau Jumlah), dan Harga/Qty (judul diawali kata "Harga").
  • Kolom lain seperti No dan Total boleh ada, tetapi diabaikan. Total dihitung otomatis.
  • Qty boleh desimal, misalnya 0.5 atau 0,5.
  • Harga boleh angka biasa atau berformat rupiah, misalnya 8000, Rp8,000, atau Rp8.000.
  • Baris tanpa nama, atau dengan Qty kosong atau 0, dilewati.
  • Hanya sheet pertama yang dibaca.

Unduh template

Import menambahkan data ke daftar yang sudah ada, tidak menimpa. Mengimpor file yang sama dua kali akan membuat data dobel. File hasil Export memiliki format berbeda, jadi tidak bisa diimpor kembali.
